# AI Security Alert Triage System

AI-powered security alert prioritization using AWS Bedrock and AI-DLC methodology.

## Features
- AI triage using AWS Bedrock (Claude)
- Plain-English explanations
- Context memory (AI-DLC)

## Tech Stack
- Flask + AWS Bedrock
- Deployed on Render

## Setup
Add these environment variables in Render:
- AWS_ACCESS_KEY_ID
- AWS_SECRET_ACCESS_KEY
- AWS_REGION
- SECRET_KEY
